Meet A²-MEAS ↓

Foundation models can generate robot actions.

We introduce A2-MEAS, an embodied multi-agent framework that coordinates reasoning, diagnostic grounding, and continuous control through a shared execution record.

SYSTEM

Code as a scaling interface

MetaBrain maintains the goal, diagnostic agents resolve physical questions, and a grounded correction interface guides A2-WLA. Nominal control repeats action and observation; diagnosis and correction are invoked when recovery is needed.

Grounded correction interface

MetaBrain’s recovery instruction, verified spatial evidence, executed history and a fresh base-policy proposal are encoded into one correction code. A residual adapter uses this code to adjust action generation, with all model parameters fixed during deployment.

Correction supervision

Correction examples are mined offline by comparing a frozen policy’s unexecuted proposals with expert demonstrations. Grounded visual evidence and corrective instructions form the training context; the expert continuation supervises the correction branch while the base policy stays frozen.

Execution and recovery

When execution becomes abnormal, the system pauses pending controls and gathers fresh evidence for a new recovery attempt. It checks the corrected candidate before execution, verifies the outcome and either resumes the unfinished task or updates the recovery query within the remaining budget.

MODEL

A2-WLA action policy

A2-WLA combines recent visual history with predicted scene features to generate continuous action chunks. Its history encoder captures observed change, while the latent world model supplies future context alongside the robot state.

INFRA

Training infrastructure

The training pipeline reduces repeated data preparation, reuses shared model computation, and distributes optimizer work across GPUs.
